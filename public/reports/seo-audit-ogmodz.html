Technical Architecture & Indexing

1. Permanent 301 vs Temporary 307 Redirects on Slug Migrations

  • Problem: In app/(public)/[locale]/store/[id]/page.js, when requests arrive at numerical or outdated product URLs (e.g. /store/40-buy-gta-v-safe-modded-cars), the system executes Next.js redirect(), which issues an HTTP 307 Temporary Redirect instead of an HTTP 301 Permanent Redirect. Search engines do not transfer link equity across 307 responses.
  • Change: Switch to permanentRedirect(`/store/${canonicalSlug}`) from next/navigation.
  • Expected effect: Consolidates historical backlinks and ranking signals directly to the target URL, preventing split rank signals across legacy URLs.

2. Relative vs Absolute Canonical URL Declarations

  • Problem: Product detail metadata defines alternates: { canonical: productPath } using relative paths (e.g. /store/buy-gta-v-safe-modded-cars). Google Search Central guidelines mandate absolute canonical URLs with protocol and hostname to prevent cross-domain or protocol confusion.
  • Change: Prepend the resolved authoritative origin (https://www.ogmodz.com) to all canonical declarations.
  • Expected effect: Guarantees indexing engines attribute authority directly to https://www.ogmodz.com, eliminating duplicate content warnings across preview environments.

The XML sitemap implementation in app/sitemap.js correctly filters games by active inventory and sets prioritized weights (1.0 for home, 0.9 for store, 0.8 for game hubs, 0.7 for products). This prevents thin-content indexation.

Structured Data & Rich Snippets

3. Game Category Hubs Lack AggregateOffer & FAQPage Schema

  • Problem: While individual product pages feature Product and AggregateRating JSON-LD, game hub pages (/store/game/gta-v, /store/game/cs2) only output BreadcrumbList and ItemList. Category hubs target high-volume head keywords where competitors show price ranges and rich FAQ dropdowns directly in Google results.
  • Change: Integrate an AggregateOffer schema calculated from active database inventory (lowest and highest price) and an expandable FAQ module with valid FAQPage schema into GameServicesPage.
  • Expected effect: Enables rich snippet enhancements (star ratings, price brackets, and collapsible FAQ questions) directly in SERP results, lifting click-through rates by an estimated 15% to 25% on commercial intent searches.

Content & Meta Calibration

4. Meta Descriptions Exceeding Search Engine Viewport Limits

  • Problem: Root layout meta description is 191 characters, and product descriptions append standard boilerplate reaching 210+ characters. Mobile and desktop SERPs truncate snippets beyond 155–160 characters with ellipses (...), cutting off value propositions and guarantees.
  • Change: Calibrate base and product description generation to 145–155 characters, front-loading primary keywords, VPN safety assurances, and conversion triggers.
  • Expected effect: Eliminates truncated snippet text in mobile search results, increasing snippet legibility and searcher confidence.
